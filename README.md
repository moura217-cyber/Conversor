# Conversor de Real e Dólar
É um site que converte real para dólar e dólar para real. A cotação vem da
AwesomeAPI, usando fetch, então o valor é buscado na hora em que a página abre.

Site publicado: https://github.com/moura217-cyber/Conversor

## O que usei
- HTML, CSS e JavaScript
- AwesomeAPI para a cotação
- IMask para formatar o campo de valor (usei porque deixa o número no padrão
  brasileiro enquanto a pessoa digita)
- Fonte Atkinson Hyperlegible, do Google Fonts

## Como rodar
É só abrir o index.html no navegador.
